# การตัดสินใจ: ไฟล์แนบ ลิงก์แชร์ และช่องข้อมูลเพิ่มเติม (P0b)

สถานะ: เจ้าของยืนยันแล้ว 2026-11-24
รายละเอียดร่างทั้งสองแบบ: `docs/plans/projects-v2-p0b.md` หัวข้อ 3–5

## ตัดสินอะไร

1. **D-4 ไฟล์แนบ = ลิงก์ไปที่ไฟล์ในคลังของคนแนบ** (`project_task_files(task_id, file_id)`) ไฟล์ที่อัปโหลดจากงานลงโฟลเดอร์ "ไฟล์แนบ · <ชื่อโปรเจค>" ในคลังของคนแนบ คนในโปรเจคดาวน์โหลดผ่าน endpoint ของงานเท่านั้น ซึ่งตรวจทั้งสมาชิกภาพและการผูกไฟล์กับงาน แล้วส่งด้วย `FileStore::send()` เดิม (ไฟล์ใน Drive ใช้ token ของเจ้าของไฟล์)
2. **D-5 ลิงก์แชร์ไม่แสดงความเห็นและไฟล์แนบ** ทั้ง API และหน้าจอของแขก
3. **D-6 ค่าช่องข้อมูลเพิ่มเติมเก็บเป็น JSON ในแถวงาน** (`project_tasks.custom`) กรอง/เรียงในเบราว์เซอร์

## ไม่เลือก และทำไม

- ที่เก็บไฟล์ของโปรเจค: ต้องทำที่เก็บ โควตา และ Google Drive ซ้ำอีกชุด
- ตารางค่าแยกต่อช่อง: JOIN ทุกครั้งที่โหลดบอร์ด ทั้งที่การกรองอยู่ในเบราว์เซอร์อยู่แล้ว

## ผลที่ตามมา

- คนแนบลบไฟล์ในเมนูไฟล์ → ไฟล์แนบหายด้วย หน้าลบไฟล์ต้องเตือนจำนวนงานที่แนบอยู่
- ย้ายค่าช่องข้อมูลเป็นตารางแยกภายหลังได้ด้วย migration เดียว ถ้าต้องกรองฝั่งเซิร์ฟเวอร์
