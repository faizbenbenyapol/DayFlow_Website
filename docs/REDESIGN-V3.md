## 0. ทำไมต้องมี v3

ผู้ใช้ไม่ผ่าน v2 ทั้ง 4 ข้อ ได้แก่ หน้าตาไม่ถูกใจ หาของไม่เจอ ความแน่นของข้อมูลไม่พอดี และใช้บนมือถือไม่สะดวก
ระหว่างเลือกทิศทาง ผู้ใช้ขอ 3 อย่างเพิ่ม:
1. สีจัดขึ้นกว่ารอบแรก แล้วค่อยลดลงมาเป็นพาสเทล
2. ไม่มีดวงอาทิตย์หรือตัวละคร
3. ของตกแต่งต้องไม่กระทบการใช้งาน ระบบเกมให้เบาลง เหลือแค่ดาวกับเปลวไฟของนิสัย

## 1. ขอบเขต

**เปลี่ยน**
- การนำทาง: เลิกใช้ rail ซ้าย 21 เมนู เปลี่ยนเป็นแถบคั่น 5 ที่ + แท็บย่อย
- tokens ทั้งชุด: สี ฟอนต์ เงา มุมโค้ง
- ส่วนประกอบกลาง: ปุ่ม การ์ด หัวหน้า checkbox แท็บ
- หน้าวันนี้: จัดใหม่ตามต้นแบบ
- หน้าที่ข้อมูลแน่น (เงิน งาน โน้ต): ปรับให้ตรงต้นแบบ
- หน้าตั้งค่า: เอาตัวเลือก "เมนูบนแถบล่างมือถือ" ออก เพราะแถบล่างเป็น 5 ที่ตายตัว

**ไม่เปลี่ยน**
- API, controller, model, ฐานข้อมูล (ไม่มี migration)
- ไม่มี framework หรือ build step ใหม่
- id และ `data-act` ที่ JS ใช้อยู่ เปลี่ยนเฉพาะเมื่อจำเป็น และแก้ e2e ตาม
- รายงาน PDF ของ `finance-report.js` (ยังใช้ Sarabun)

## 2. โครงข้อมูล: 5 ที่

| ที่ | สี | เมนูข้างใน (แท็บย่อย) |
|---|---|---|
| วันนี้ `today` | เหลืองเนย | วันนี้, สรุปผล |
| งาน `work` | ฟ้า | งาน, โปรเจค, แพลนเนอร์ |
| ชีวิต `life` | ชมพู | นิสัย, โฟกัส, ทักษะ, ออกกำลังกาย, อาหาร |
| เงิน `money` | มิ้นต์ | รายรับรายจ่าย, รายจ่ายประจำ, หุ้น |
| คลัง `vault` | พีช | โน้ต, จดด่วน, ลิงก์, ไฟล์, ส่งไฟล์ |
| เครื่องมือ `tools` | ม่วงลาเวนเดอร์ | แปลงไฟล์, ผู้ช่วย AI, เครื่องคิดเลข (ไม่มีแถบคั่น เข้าจากปุ่ม "ทั้งหมด" และ Ctrl K) |

- `AppMenus::GROUPS` กลายเป็น 6 กลุ่มนี้ และ `MENUS` ย้ายแต่ละเมนูเข้ากลุ่มใหม่ หน้าตั้งค่าเมนูและ command palette จึงจัดกลุ่มตามนี้เอง
- แถบคั่นของที่หนึ่งพาไปเมนูแรกที่ยังแสดงอยู่ในที่นั้น ถ้าผู้ใช้ซ่อนทุกเมนูในที่นั้น แถบคั่นก็หายไปด้วย
- ที่ปัจจุบันคำนวณจาก path แล้วใส่เป็น `data-place` บน `<html>` เพื่อให้ CSS ใช้สีของที่นั้น

## 3. Tokens

### 3.1 สี — สว่าง

| token | ค่า | ใช้กับ |
|---|---|---|
| `--mat` | `#DCE8E0` | พื้นโต๊ะรอบหน้า |
| `--paper` | `#FFFFFF` | หน้าสมุด การ์ด |
| `--paper-sunk` | `#F5F7F6` | ช่องกรอก แถวที่ hover |
| `--rule` | `#E6EAE8` | เส้นคั่นตกแต่ง |
| `--rule-strong` | `#7E8794` | ขอบช่องกรอก checkbox (≥3:1) |
| `--edge` | `#3A3F4A` | ขอบปุ่มและแถบคั่น |
| `--ink` | `#2B2F38` | ตัวหนังสือหลัก |
| `--pencil` | `#59606C` | ตัวหนังสือรอง (≥4.5:1) |
| `--stamp-red` | `#B83232` | เลยกำหนด รายจ่าย ลบ และเครื่องหมายถูก |
| `--ledger-green` | `#1F7A52` | รายรับ เสร็จแล้ว |
| `--caution` | `#8A5800` | ครบวันนี้ |
| `--highlighter` | `#FFEFB0` | ผลค้นหา แถวที่เพิ่งเปลี่ยน |

พาสเทลของแต่ละที่มี 2 ระดับ: `--butter`/`--butter-2`, `--sky`/`--sky-2`, `--blush`/`--blush-2`, `--mint`/`--mint-2`, `--peach`/`--peach-2`, `--lilac`/`--lilac-2`
ระดับ 1 ใช้เป็นพื้นของแถบคั่นและการ์ดสี ระดับ 2 ใช้กับไฮไลต์หัวข้อ เส้นบนการ์ด และเส้นใต้แท็บย่อย
`--place` / `--place-2` ชี้ไปที่คู่สีของที่ปัจจุบัน
**กติกา:** พาสเทลไม่เคยใช้บอกสถานะ สถานะใช้แค่ `--stamp-red` `--ledger-green` `--caution`

### 3.2 สี — มืด

โต๊ะเขียวเข้ม หน้าสมุดเทาเข้ม ส่วนพาสเทลกดให้เข้มลงจนตัวหนังสือสีอ่อนอ่านได้ ค่าทั้งหมดอยู่ใน `tokens.css` และ `scripts/check-contrast.mjs` ตรวจทุกคู่สี

### 3.3 สีประจำวัน

สวิตช์ "สีประจำวัน" ยังอยู่ แต่เปลี่ยนหน้าที่ใหม่ ถ้าเปิดไว้ ไฮไลต์ใต้วันที่บนหน้าวันนี้จะเป็นพาสเทลประจำวัน ถ้าปิด จะใช้สีเนยของที่ "วันนี้"

### 3.4 ตัวอักษร

| token | ฟอนต์ | ใช้กับ |
|---|---|---|
| `--font` | Anuphan (ไทยและละตินในตระกูลเดียว, variable 100–700) | ทุกอย่าง |
| `--font-hand` | Mali 600/700 | หัวข้อหน้า หัวการ์ด ตัวเลขใหญ่ |
| `--font-num` | Mali 700 | ตัวเลขใหญ่เท่านั้น (ยอดคงเหลือ วันที่บนแผ่นปฏิทิน) ตัวเลขในตารางเป็น Anuphan + tabular-nums |
| `--font-mono` | IBM Plex Mono (ไฟล์เดิม) | นาฬิกา รหัส |

self-host ทั้งหมดใน `public/assets/fonts/` ไฟล์ IBM Plex Sans Thai/Serif ลบได้หลัง Phase 5

### 3.5 รูปทรง

- มุมโค้ง: ปุ่มและช่องกรอก 8px, การ์ด 6px, dialog 12px
- ปุ่ม: ขอบ 1.5px สี `--edge` และเงาทึบ 2px ใต้ปุ่ม กดแล้วปุ่มยุบลง 2px
- การ์ด: ขอบ 1px `--rule` และเส้นบน 3px เป็นสีของที่ที่ข้อมูลมา
- เทปวาชิ: ใช้ได้เฉพาะบนการ์ดของหน้าวันนี้ ขนาด 54×16px ที่มุมซ้ายบน
- ไม่มีอะไรเอียง ไม่มีห่วงสันสมุด ไม่มีจุดบนกระดาษ

## 6. ความเสี่ยงและสิ่งที่ต้องระวัง

- **e2e-shell.mjs** อ้างถึง `#appRail`, `.nav-item`, `.tabbar` และปุ่ม "ทั้งหมด" ใน Phase 2 จะเก็บ id `appRail` ไว้ที่แถบคั่น แล้วแก้ชุดทดสอบให้ตรงกับโครงใหม่
- **mobile_tabs** ยังอยู่ในฐานข้อมูลและใน export/import ของบัญชี ไม่ต้องลบ แค่ไม่มีใครอ่านมันแล้ว
- **ฟอนต์ Mali** ใช้เฉพาะหัวข้อ ห้ามใช้กับเนื้อความหรือตัวเลขในตาราง
- **ความยาวของ label ไทย** บนแถบคั่นมือถือ: "ชีวิต" กับ "คลัง" สั้น แต่ต้องเผื่อฟอนต์ใหญ่ที่ผู้ใช้ตั้งไว้ในเครื่อง
