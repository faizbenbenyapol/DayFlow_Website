## 1. สรุปสิ่งที่ส่งมอบ

ทุกกล่องที่ถามยืนยัน ถามข้อความ หรือแจ้งผล เป็นกล่องของ DayFlow เองในธีม v3 ไม่มี SweetAlert หรือกล่องของเบราว์เซอร์อีกแล้ว ข้อความแจ้ง (toast) เป็นแผ่นโน้ตพาสเทลที่มีตราบอกชนิดและปุ่มปิด รายการในทุกเมนูอ่านง่ายขึ้น โดยรายรับเป็นสีเขียว รายจ่ายเป็นสีแดง ตัวเลขหลักเป็นสีหมึกตัวหนา และข้อความรองเข้มขึ้น ลิงก์แชร์ติดตั้งเป็นแอปของลิงก์นั้นได้ เปิดไอคอนแล้วกลับมาที่หน้าแชร์เสมอ หุ้นแยกรายการซื้อกับขาย แต่ละการขายบอกกำไรของครั้งนั้น และบอกว่าเงินที่ได้เก็บไว้ลงทุนต่อหรือถอนออก ถ้าถอนออก ระบบจะลงรายการถอนในแท็บเงินลงทุนให้

## 6. คู่มือการใช้งาน

### 6.1 บันทึกการขายหุ้น
1. หุ้น → บันทึกรายการ → เลือก "ขาย" แล้วกรอกหุ้น จำนวน ราคา ค่าธรรมเนียม
2. ส่วน "เงินจากการขายนี้" มีสองทางเลือก ค่าเริ่มต้นเป็น "เก็บไว้ลงทุนต่อ" ซึ่งไม่เปลี่ยนเงินต้น และกำไรไม่นับเป็นเงินต้น
3. ถ้าเลือก "ถอนออก" ยอดถอนเติมให้ตามจำนวน × ราคา − ค่าธรรมเนียม และสกุลเงินตามรายการ (หุ้นตลาดอื่นที่ไม่ใช่ THB/USD ตั้งเป็น THB) แก้ได้ก่อนบันทึก แล้วรายการถอนจะไปอยู่ในแท็บเงินลงทุน พร้อมป้าย "จากการขาย"
4. แท็บซื้อขาย → "รายการขาย": แต่ละแถวเห็นยอดที่ได้รับ กำไร/ขาดทุนของครั้งนั้น และป้ายเงินที่ได้ (ลงทุนต่อ / ถอน X / ไม่ได้ระบุ)

ข้อความที่อาจเจอ:
- "รายการนี้มาจากการขายหุ้น แก้หรือลบที่รายการขายในแท็บซื้อขาย": รายการถอนที่ระบบสร้างให้ ต้องแก้ที่รายการขาย
- "ยอดที่ถอนออกต้องเป็น THB หรือ USD": แท็บเงินลงทุนรับแค่สองสกุลนี้

### 6.2 ติดตั้งลิงก์แชร์เป็นแอป (คนดูลิงก์)
1. เปิดลิงก์แชร์บนมือถือ แล้วกด "ติดตั้งแอป" (Android) หรือ แชร์ → "เพิ่มไปยังหน้าจอโฮม" (iPhone)
2. ไอคอนชื่อ "<ชื่อลิงก์>" เปิดมาเจอหน้าแชร์เสมอ ถ้าลิงก์หมดอายุ จะเห็นหน้า "ลิงก์หมดอายุ"
3. คนที่เคยติดตั้งจากลิงก์แชร์ก่อนรอบนี้ ต้องลบไอคอนเก่าแล้วติดตั้งใหม่หนึ่งครั้ง

## 7. โครงสร้างระบบสำหรับผู้ดูแล

```
ปุ่มในหน้า → confirmAction / askText / showNotice → showDialog (คิว) → <dialog class="sheet df-dialog">
บันทึกขาย → StocksController::validateData → Stock::create/update (ธุรกรรม) → syncSaleWithdrawal → stock_capital_flows
แสดงรายการ → Stock::listForUser (+ LEFT JOIN รายการถอน) + realizedBySale → averageCostWalk (สูตรเดียวกับ portfolioForUser)
หน้าแชร์ → <link rel=manifest> → /shared/<token>/manifest.webmanifest → start_url /shared/<token>
```

- schema ใหม่: `stock_transactions.proceeds_action` (NULL = ไม่ได้ระบุ), `stock_capital_flows.sale_txn_id` พร้อม UNIQUE และ FK สองคอลัมน์ `(sale_txn_id, user_id)` → `(id, user_id)` ON DELETE CASCADE รายการถอนจึงชี้ได้เฉพาะการขายของเจ้าของเดียวกัน
- สำรอง/นำเข้าข้อมูล: `AccountData::TABLES` แปลง `sale_txn_id` ตาม id ใหม่ ถ้าหาไม่เจอจะล้างเป็น NULL
- จุดที่ต้องระวัง:
  - กล่องใหม่ต่อยอดจาก `dialog.sheet` ใน `shell.css` ซึ่งโหลดหลัง `components.css` selector ของกล่องจึงต้องเป็น `dialog.sheet.df-dialog`
  - CSS reset ตั้ง `margin: 0` ให้ทุกอย่าง กล่องจึงต้องตั้ง `margin: auto` เองจึงจะอยู่กลางจอ (`.sheet` ทำให้แล้ว)

**ห้าอย่างที่แนะนำให้ทำก่อน**
1. ภาษีเงินได้บุคคลธรรมดาและค่าลดหย่อน: ใช้รายรับที่บันทึกอยู่แล้ว และเห็นภาษีทั้งปีก่อนยื่น

3. แบ่งบิลกับเพื่อน: ใช้บ่อยและเล็ก ทำเสร็จได้เร็ว
4. อ่านยอดจากรูปใบเสร็จ/สลิป: ลดงานกรอกที่ทำทุกวัน รายรับรายจ่ายจึงครบขึ้น
