## 1. สรุปสิ่งที่ส่งมอบ

เฟส 1 แก้จุดกวนใจที่เจอจากการใช้จริงและทำกราฟการเงินใหม่ เมนู "ยังไม่จัด" หายจากทุกที่ที่แสดงเมนู แต่กล่อง "ยังไม่จัด" ในหน้างานยังอยู่ ติ๊กงาน งานโปรเจกต์ หรือนิสัยแล้วไม่มีป๊อปอัพเด้ง (ยกเว้นตอนบันทึกไม่สำเร็จ) เปอร์เซ็นต์เป้าหมายทักษะเป็นจำนวนเต็ม เปลี่ยนหน้าแล้วเนื้อหาไม่ขยับซ้ายขวา กราฟการเงินมีแท่งมน สีที่อ่านออกทั้งธีมสว่างและมืด สลับดูได้สามมุมมอง (รายเดือน ตามหมวด ก้อนใหญ่สุด 10 อันดับ) และปีที่ไม่มีรายการบอกเป็นข้อความแทนแกนเปล่า

เฟส 2 ทำให้ผู้ใช้จัดเมนูเองได้: เปลี่ยนชื่อหมวดใหญ่ทั้ง 6 ย้ายเมนูไปหมวดอื่น (หน้านั้นเปลี่ยนเป็นสีของหมวดใหม่) ค้นหาเมนูในหน้าตั้งค่า และคืนค่าเริ่มต้นได้ในปุ่มเดียว หน้าตั้งค่ามีแท็บ "เกี่ยวกับแอป" ที่บอกเวอร์ชัน 3.0.0 พร้อมรายการสิ่งที่เปลี่ยนของทุกเวอร์ชันเป็นภาษาคนทั่วไป และปุ่มติดตั้ง DayFlow ลงเครื่อง (บน iPhone/iPad แสดงวิธีกดแทน)

## 5. การรันและการนำขึ้นระบบ (deploy)

รันเหมือนเดิม (ดู CLAUDE.md) deploy เป็นงานของเจ้าของระบบ ไฟล์ CSS/JS ใหม่ถูกโหลดเองด้วย `?v=` เดิม

**เฟส 2 ต้องรัน migration ก่อนเปิดใช้:** `php scripts/migrate.php` (รันแล้วในเครื่องทดสอบ: ครั้งแรก "1 applied" และ `--force` ซ้ำไม่มี error) ถ้าไม่รัน การบันทึกในหน้าตั้งค่าเมนูจะได้ "บันทึกการตั้งค่าเมนูไม่สำเร็จ" ส่วนหน้าอื่นใช้ค่าตั้งต้นต่อได้ (อนุมาน จากโค้ด `menu_layout ?? 'null'`)

เลขเวอร์ชันที่แอปแสดงมาจากตัวแรกใน `config/releases.php` (ตอนนี้ 3.0.0) ติด tag git ให้ตรงตอน deploy และใส่วันที่ของเวอร์ชันนั้นในไฟล์

## 6. คู่มือการใช้งาน

1. กราฟการเงิน: หน้า รายรับรายจ่าย เลื่อนลงไปส่วนกราฟปี
2. กด "รายเดือน" ดูรายรับคู่รายจ่ายแต่ละเดือน เลือก "แท่ง" หรือ "เส้น" ได้ ชี้เดือนไหนเห็นทั้งสองค่า
3. กด "ตามหมวด" ดูรายจ่ายทั้งปีแยกหมวด มากไปน้อย ถ้ามีเกิน 10 หมวด หมวดที่เล็กกว่ารวมเป็นแท่ง "หมวดอื่นอีก N หมวด"
4. กด "ก้อนใหญ่สุด" ดูรายจ่ายเดี่ยว 10 รายการที่ใหญ่สุดของปี ชี้แท่งเห็นชื่อเต็ม จำนวนเงิน วันที่ และหมวด
5. เปลี่ยนปีจากช่องปี มุมมองที่เลือกไว้ยังอยู่
7. จัดเมนู: ตั้งค่า > เมนู พิมพ์ชื่อหมวดใหม่ในช่อง "ชื่อหมวด" (ลบให้ว่างคือกลับชื่อเดิม) เลือกหมวดท้ายแถวเพื่อย้ายเมนู ใช้ช่องค้นหาเมื่อเมนูเยอะ แล้วกด "บันทึกเมนู" ส่วน "คืนค่าเริ่มต้น" ล้างทุกอย่าง (ถามยืนยันก่อน)
8. เกี่ยวกับแอป: ตั้งค่า > เกี่ยวกับแอป เห็นเวอร์ชัน ปุ่มติดตั้ง และรายการอัปเดต กดหัวเวอร์ชันเพื่อเปิดอ่าน
9. ข้อความที่อาจเห็นในเฟส 2: "ชื่อหมวดยาวได้ไม่เกิน 30 ตัวอักษร ลองตั้งให้สั้นลง" = ชื่อยาวเกิน ไม่มีอะไรถูกบันทึก; "เบราว์เซอร์นี้ยังไม่เสนอให้ติดตั้ง" = เบราว์เซอร์ติดตั้งไม่ได้ หรือติดตั้งไปแล้ว
6. ข้อความที่อาจเห็น: "ยังไม่มีรายการในปีนี้" = ปีนั้นไม่มีทั้งรายรับและรายจ่าย; "ยังไม่มีรายจ่ายในปีนี้" = มีแต่รายรับ (ในมุมมองตามหมวดและก้อนใหญ่สุด)

## 7. โครงสร้างระบบสำหรับผู้ดูแล

```
ช่องปี / ปุ่มมุมมอง ─▶ finance.js loadChart(year)
                       │ GET /api/finance/chart?year=2026 (request เดียวได้ครบสามมุมมอง)
                       ▼
          FinanceController::apiChart
             ├─ Finance::getYearlyChart   → chart (12 เดือน)
             └─ Finance::getYearBreakdown → by_category, top_expenses
                       │
                       ▼
          drawChart() → chartRows() → monthsChartConfig() หรือ rankingChartConfig()
                      └─ fillChartTable() ตารางซ่อนสำหรับโปรแกรมอ่านหน้าจอ
```

- core/AppMenus.php → รายการเมนูกลาง ทุกจุดที่แสดงเมนูอ่านจากที่นี่
- models/Finance.php → `getYearBreakdown()` สอง query (ตามหมวด, 10 อันดับ) ค่าคงที่ `UNCATEGORISED` ใช้ร่วมกับสรุปรายเดือน
- public/assets/js/finance.js → ส่วน "the year chart" ทั้งหมด
- public/assets/css/tokens.css → `--chart-income` / `--chart-expense` สีแท่ง ค่าเดียวทั้งสองธีม
- public/assets/js/app.js → `chartTheme()` คืน `chartIncome` / `chartExpense` เพิ่ม (ค่า `income` / `expense` เดิมยังเป็นของกราฟหุ้น)

เฟส 2:

```
หน้าตั้งค่า (ชื่อหมวด, หมวดของเมนู, ติ๊ก, ลำดับ)
      │ POST /api/settings/menus {menus, order, layout}
      ▼
SettingsController::apiMenus ─ AppMenus::nameError (EDGE-4) ─▶ user_settings.menu_layout
                                                                      │
header.php ◀─ AppMenus::layout(ค่าที่บันทึก) ◀─────────────────────────┘
  ├─ grouped(): แท็บบน แถบข้าง หน้าทั้งหมด ด้วยชื่อหมวดและหมวดใหม่
  └─ groupForPath(): data-place สีของหน้า
```

- core/AppMenus.php → `layout()` อ่านและทำความสะอาดค่าที่บันทึกทุกครั้ง (ไฟล์สำรองที่นำเข้าก็ผ่านตรงนี้) `groupOf()` / `groupName()` ใช้แทนการอ่าน `MENUS[..]['group']` และ `GROUPS[..]` ตรง ๆ
- config/releases.php → ข้อความอัปเดต ตัวแรกคือเวอร์ชันปัจจุบัน
- public/assets/js/settings-install.js → สถานะปุ่มติดตั้งสี่แบบ

จุดที่ต้องระวัง:
- endpoint ที่รับ object หรือ list ใน JSON ต้องใช้ `Request::list()` ถ้าใช้ `Request::input($key, null)` ค่าที่เป็น object จะกลายเป็น null เงียบ ๆ (เคยทำให้ layout ไม่ถูกบันทึกระหว่างทำเฟส 2)
- เพิ่มคอลัมน์ใน user_settings ที่ผู้ใช้ตั้งเอง ต้องเพิ่มใน `AccountData::SETTINGS` (และ `JSON_SETTINGS` ถ้าเป็น JSON) ไม่งั้นหายตอนสำรองและนำเข้า
- เพิ่มเวอร์ชันใหม่: เพิ่มบนสุดของ `config/releases.php` เขียนแบบคนใช้แอปอ่าน test จะแดงถ้ามีชื่อไฟล์ ฟังก์ชัน หรือ path
- อย่าเปลี่ยน `theme.income` / `theme.expense` ใน `chartTheme()` กราฟหุ้นใช้ระบายกำไร/ขาดทุน
