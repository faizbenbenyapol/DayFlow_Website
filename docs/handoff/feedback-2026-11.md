## 1. สรุปสิ่งที่ส่งมอบ

เฟส 1 แก้จุดกวนใจที่เจอจากการใช้จริงและทำกราฟการเงินใหม่ เมนู "ยังไม่จัด" หายจากทุกที่ที่แสดงเมนู แต่กล่อง "ยังไม่จัด" ในหน้างานยังอยู่ ติ๊กงาน งานโปรเจกต์ หรือนิสัยแล้วไม่มีป๊อปอัพเด้ง (ยกเว้นตอนบันทึกไม่สำเร็จ) เปอร์เซ็นต์เป้าหมายทักษะเป็นจำนวนเต็ม เปลี่ยนหน้าแล้วเนื้อหาไม่ขยับซ้ายขวา กราฟการเงินมีแท่งมน สีที่อ่านออกทั้งธีมสว่างและมืด สลับดูได้สามมุมมอง (รายเดือน ตามหมวด ก้อนใหญ่สุด 10 อันดับ) และปีที่ไม่มีรายการบอกเป็นข้อความแทนแกนเปล่า

## 6. คู่มือการใช้งาน

1. กราฟการเงิน: หน้า รายรับรายจ่าย เลื่อนลงไปส่วนกราฟปี
2. กด "รายเดือน" ดูรายรับคู่รายจ่ายแต่ละเดือน เลือก "แท่ง" หรือ "เส้น" ได้ ชี้เดือนไหนเห็นทั้งสองค่า
3. กด "ตามหมวด" ดูรายจ่ายทั้งปีแยกหมวด มากไปน้อย ถ้ามีเกิน 10 หมวด หมวดที่เล็กกว่ารวมเป็นแท่ง "หมวดอื่นอีก N หมวด"
4. กด "ก้อนใหญ่สุด" ดูรายจ่ายเดี่ยว 10 รายการที่ใหญ่สุดของปี ชี้แท่งเห็นชื่อเต็ม จำนวนเงิน วันที่ และหมวด
5. เปลี่ยนปีจากช่องปี มุมมองที่เลือกไว้ยังอยู่
6. ข้อความที่อาจเห็น: "ยังไม่มีรายการในปีนี้" = ปีนั้นไม่มีทั้งรายรับและรายจ่าย; "ยังไม่มีรายจ่ายในปีนี้" = มีแต่รายรับ (ในมุมมองตามหมวดและก้อนใหญ่สุด)

## 7. โครงสร้างระบบสำหรับผู้ดูแล

```
ช่องปี / ปุ่มมุมมอง ─▶ finance.js loadChart(year)
                       │ GET /api/finance/chart?year=2026 (request เดียวได้ครบสามมุมมอง)
                       ▼
          FinanceController::apiChart
             ├─ Finance::getYearlyChart   → chart (12 เดือน)
             └─ Finance::getYearBreakdown → by_category, top_expenses
                       │
                       ▼
          drawChart() → chartRows() → monthsChartConfig() หรือ rankingChartConfig()
                      └─ fillChartTable() ตารางซ่อนสำหรับโปรแกรมอ่านหน้าจอ
```

- core/AppMenus.php → รายการเมนูกลาง ทุกจุดที่แสดงเมนูอ่านจากที่นี่
- models/Finance.php → `getYearBreakdown()` สอง query (ตามหมวด, 10 อันดับ) ค่าคงที่ `UNCATEGORISED` ใช้ร่วมกับสรุปรายเดือน
- public/assets/js/finance.js → ส่วน "the year chart" ทั้งหมด
- public/assets/css/tokens.css → `--chart-income` / `--chart-expense` สีแท่ง ค่าเดียวทั้งสองธีม
- public/assets/js/app.js → `chartTheme()` คืน `chartIncome` / `chartExpense` เพิ่ม (ค่า `income` / `expense` เดิมยังเป็นของกราฟหุ้น)

จุดที่ต้องระวัง:
- อย่าเปลี่ยน `theme.income` / `theme.expense` ใน `chartTheme()` กราฟหุ้นใช้ระบายกำไร/ขาดทุน
- เปอร์เซ็นต์ทักษะคิดจากวินาทีที่เป็นจำนวนเต็ม (`secondsDone * 100 / (target * 3600)`) ถ้าเปลี่ยนเป็น `hours / target * 100` แล้ว floor จะได้ 28% แทน 29% เพราะทศนิยมของ JS
- เปลี่ยนสีแท่ง ให้รันตัวตรวจ palette กับทั้งพื้น #FFFFFF และ #1F2422 ก่อน
