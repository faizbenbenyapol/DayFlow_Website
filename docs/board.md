# บอร์ดกลาง DayFlow

- **บอร์ดหลัก:** Excaliself (Excalidraw 0.18 ที่เจ้าของโฮสต์เองที่ draw.benyapol.com) ย้ายมาเมื่อ 2026-11-27
- **ลิงก์อยู่ใน `docs/board.local.md`** ไฟล์นั้นไม่ขึ้น git เพราะใครมีลิงก์ก็แก้บอร์ดได้ และ repo นี้เป็น public ถ้าในเครื่องไม่มีไฟล์นี้ ให้ขอลิงก์จากเจ้าของ
- บอร์ดเดิมบน Claude Whiteboard เลิกใช้แล้ว
- วาดจาก: `public/index.php`, `core/Router.php`, `core/AppMenus.php`, `cron.php`, `sql/migrations/*`, `docs/decisions/*`, `docs/plans/projects-v2-*.md`, `docs/requirements/*`, `CHANGELOG.md`, `git log` และ `gh pr list`

- **ต้นฉบับเนื้อหา:** `docs/board.content.json` (ขึ้น git) แก้ไฟล์นี้ก่อน แล้วค่อยทำบอร์ดให้ตรง ทำตามสกิล `project-board` (`~/.claude/skills/project-board`) ซึ่งกฎกลางสั่งให้ใช้ทุกโปรเจกต์ และอัปเดตทุกรอบงาน

บอร์ดมีไว้ให้คนกับ AI เข้าใจงานตรงกัน ครึ่งบนเขียนเป็นภาษาคน ไม่มีชื่อไฟล์ ครึ่งล่างเป็นภาคผนวกระดับโค้ด

## ครึ่งบน: ทำงานร่วมกัน (อ่านตามเลข)

| หัวข้อ | ตอบคำถามว่า | AI อัปเดตเมื่อไร |
| --- | --- | --- |
| วิธีใช้บอร์ด (ขวาบน) | คุณทำอะไร AI ทำอะไรกับบอร์ด สีหมายถึงอะไร | เมื่อวิธีทำงานเปลี่ยน |
| 1 ตอนนี้กำลังทำอะไร | เป้าหมาย ความคืบหน้า X/9 การ์ด เสร็จแล้ว / ถัดไป / ยังไม่เริ่ม พร้อม "ลองดู" | ทุกครั้งที่จบขั้น: ย้ายการ์ด แก้ตัวเลขความคืบหน้า |
| 2 รอคุณตัดสิน (ส้ม) | เรื่องที่ต้องให้เจ้าของตอบ แต่ละข้อมีคำแนะนำ และบอกว่า AI จะทำอะไรถ้ายังไม่ตอบ | อ่านบรรทัด "คำตอบ:" ก่อนเริ่มงานทุกครั้ง ข้อที่ตอบแล้วย้ายไปหัวข้อ 3 |
| 3 ตกลงกันแล้ว | การตัดสินใจพร้อมเหตุผลเป็นภาษาคน | เมื่อมีการตัดสินใจใหม่ |
| 4 แบ่งงานกันแบบนี้ | หน้าที่ของคุณ หน้าที่ของ AI และเรื่องที่ AI ต้องถามก่อน | เมื่อกติกาเปลี่ยน |
| 5 ระบบในภาพเดียว | ระบบทั้งหมดแบบไม่มีชื่อไฟล์ | เมื่อมีส่วนใหม่ของระบบ |
| 6 คำที่เราใช้ตรงกัน | ความหมายของคำที่ใช้คุยกัน | เมื่อมีคำใหม่ |
| 7 ทางที่ผ่านมา + บันทึก | เส้นเวลาของโปรเจค และบันทึกการเปลี่ยนแปลง | ทุกครั้งที่จบขั้น: เพิ่มบรรทัดบนสุดของบันทึก |

## ครึ่งล่าง: ภาคผนวกระดับโค้ด (ก–ญ)

| ภาคผนวก | เนื้อหา |
| --- | --- |
| ก แผนที่ระบบระดับไฟล์ | หน้าบ้าน → หลังบ้าน → ข้อมูลและภายนอก พร้อม path (สีพีช = ส่วนที่ขั้นล่าสุดแตะ) |
| ข รีวิว P1 ทีละ commit | slice · commit · ไฟล์ที่ควรเปิด · test · สถานะ |
| ค หนึ่งคำขอผ่านอะไรบ้าง | 9 ขั้นใน `Router::dispatch()` พร้อมเลขบรรทัด |
| ง กฎที่เคยพลาด | 7 กฎจาก CLAUDE.md พร้อมที่ดูในโค้ด |
| จ เมนู → ไฟล์ | 23 เมนู: URL controller model JS ตาราง DB |
| ฉ งานเบื้องหลัง (cron) | 7 ขั้นใน `cron.php` |
| ช คำศัพท์เต็ม | 22 คำ ↔ ชื่อในโค้ด ↔ ที่มา |
| ซ ตารางของเมนูโปรเจค | ตาราง project_* 16 ตาราง และลูกศร FK |
| ฌ การตัดสินใจฉบับเต็ม | D-1 ถึง D-8, CR-2, Google Drive พร้อมเอกสารอ้างอิง |
| ญ ตรวจงานยังไง | คำสั่งตรวจ 5 ตัว และโฟลเดอร์เอกสาร |

## วิธีอัปเดต

- แก้ทีละจุด: ดับเบิลคลิกข้อความบนบอร์ด แก้ แล้วกด Esc ข้อความในกล่องเป็น text แยกกันทีละบรรทัดหรือทีละย่อหน้า
- เลื่อนดูบอร์ดด้วยเครื่องมือมือ (กด H) อย่าลากด้วยเครื่องมือเลือก เพราะถ้าจุดเริ่มลากอยู่บนข้อความ ข้อความนั้นจะถูกย้าย
- เพิ่มของชุดใหญ่: สร้าง JSON รูปแบบ `excalidraw/clipboard` ใส่ clipboard แล้วให้เจ้าของคลิกกระดานแล้วกด Ctrl+V เอง เพราะการกด Ctrl+V จากเครื่องมืออัตโนมัติอ่าน clipboard ไม่ได้
